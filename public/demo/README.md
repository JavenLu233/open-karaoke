# 演示素材来源

本目录的演示素材用于本地开发预览。仓库默认加载 `Auld Lang Syne`，素材来源如下：

- 音频：[`Auld Lang Syne.ogg`](https://commons.wikimedia.org/wiki/File:Auld_Lang_Syne.ogg)，Frank C. Stanley，1910 年录音。Wikimedia Commons 页面标注为 Public Domain。
- 封面：[`37 Auld Lang Syne.png`](https://commons.wikimedia.org/wiki/File:37_Auld_Lang_Syne.png)，公版乐谱图片。
- 歌词与时间：[`TimedText:Auld Lang Syne.ogg.en.srt`](https://commons.wikimedia.org/wiki/TimedText:Auld_Lang_Syne.ogg.en.srt)，转换为本项目使用的 LRC 格式；歌词文本来自 Robert Burns 的公版作品。

素材来源页面的许可信息可能因司法辖区而异，正式发布前请根据使用地区再次确认。

本地测试时可以在此目录放置自己的音频、封面和 LRC；项目根目录的 `.gitignore` 会忽略本地的用户素材。
